🎯 What Is This Tool?

AWS Cloud Practitioner Flashcards is a simple yet powerful web-based study application built for anyone preparing for the AWS Certified Cloud Practitioner (CLF-C02) exam. No installation required — just download, open, and start learning. It runs entirely in your browser and works offline after the initial download.

✨ Key Features

🃏 Interactive AWS Service Cards

Flip through detailed cards covering core AWS services, pricing models, architecture, security, and more.

📂 Category-Based Practice

Focus on specific domains like compute, storage, database, networking, or security to target weak areas.

📊 Session Results

Track your progress with instant feedback after each study session. See which topics need more review.

🌐 Local & Offline

Study anywhere — on a plane, in a café, or at home — without needing an internet connection after download.

Follow these three simple steps to start studying in under 2 minutes.

📥 Download & Install

Step 1: Visit the official download page:

🌐 Visit this link to download the application

Step 2: On the GitHub page, click the green "Code" button, then select "Download ZIP". Alternatively, scroll down to the Releases section and download the latest release ZIP file.

Step 3: Once the ZIP file is downloaded, right-click it and choose "Extract All". Pick a folder (e.g., Desktop or Documents), then extract.

Step 4: Open the extracted folder and double-click index.html. It will open in your default web browser. That's it — you're ready to study!

💡 Pro Tip: Bookmark the index.html file or create a shortcut on your desktop for quick access. Since everything runs locally, you can even rename the folder and move it anywhere.

🧠 How to Use the Flashcards

  • 1. Choose a category from the main menu — e.g., "Compute", "Storage", "Security", or "All Cards".
  • 2. Click or tap a card to flip it and reveal the answer or explanation on the back.
  • 3. Rate yourself — mark cards as "Known" or "Need Review" to filter them later.
  • 4. Review session results at the end to see your accuracy and focus on weak areas.

❓ Frequently Asked Questions

Do I need to install anything?

No. The app runs directly in your browser. You only need to download and extract the ZIP file, then open index.html.

Does it work offline?

Yes. After the initial download, no internet connection is required. All flashcards and logic are stored locally.

Is it free?

Absolutely. This is an open-source project, completely free to use and share.

Can I add my own cards?

Yes! You can edit the data file inside the folder (usually a JavaScript or JSON file) to add or modify cards. Instructions are included in the package.

📈 Study Tips for CLF-C02

The AWS Cloud Practitioner exam tests your understanding of AWS cloud concepts, core services, security, pricing, and support. Use these flashcards daily for 15-20 minutes. Focus on one category per session, then mix them up. Review session results to identify patterns — if you consistently miss storage questions, spend extra time on that category.
